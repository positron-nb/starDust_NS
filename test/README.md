# Test data and test workflow

## `sample_data/` contents

| File | Provenance | Purpose |
|---|---|---|
| `synthetic_room.ply` | **Synthetic.** Generated by `scripts/make_test_splat.py --spacing 0.03 --seed 7`. It is a 4 × 3 × 2.6 m box room with a door, a window, a table and a sofa block (79,102 splats, 5.1 MB, z-up, standard 3DGS binary PLY layout as written by `ns-export gaussian-splat`). | Tests `splat_info.py`, `splat-transform` conversion, and viewer loading, alignment and bounds **without** a GPU or real capture. It is not a reconstruction and is labelled as such in the viewer. |
| `frames/` *(added after capture)* | **Real.** About 30 downsampled frames (1600 px) from the team's own room capture, chosen evenly through the route, with nothing private visible. | Tests `check_images.py`, and runs a small real COLMAP and Splatfacto job (`-MaxIters 3000`) in minutes. |

The full raw video is **not** committed (size and privacy). The complete frame set used for the submitted model is in the Google Drive folder.

## Tests

### T1: pre-processing on a generated video (no capture needed)

```powershell
$ff = python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())"
& $ff -y -f lavfi -i "testsrc2=size=1920x1080:rate=30:duration=10" -pix_fmt yuv420p test_out\test.mp4
python scripts\extract_frames.py test_out\test.mp4 test_out\ws\images --fps 2
python scripts\check_images.py test_out\ws\images
```

Expected result: 20 of 60 candidate frames kept at 1600×900, with `quality_summary.json` reporting 20 kept and 0 rejected. The run also prints a warning that fewer than 40 frames is too few for COLMAP, which is intended. Measured on 2026-10-27: this exact output.

### T2: splat inspection and web conversion

```powershell
python scripts\splat_info.py test\sample_data\synthetic_room.ply
npx @playcanvas/splat-transform@3.10.1 test\sample_data\synthetic_room.ply --filter-nan test_out\synthetic_room.sog -w
```

Expected result: 79,102 splats, 0 non-finite, bounds `[0,0,0]`–`[4,3,2.6]`, and a floor estimate of 0.0. The SOG file is about 151 KB.
